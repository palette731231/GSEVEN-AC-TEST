集雅社 空調品牌智慧選購 SO SMART!

回答5個問題，推薦您最適合的空調品牌與型號，加碼回饋"心理性格畫像"

1. 您的預算與品牌定位偏好？

👑 頂級旗艦 / 美學品牌

品質優先、極致靜音、獨家淨化與智慧科技

⚖️ 高 CP 值與專業大風量

重風量速冷、耐用強效、價格親民性價比高

💡 彈性不限 / 無特別喜好

不限品牌定位，完全依照功能匹配度推薦

2. 您的使用頻率與省電要求？

⚡ 長時間超高頻率使用

夏季每日開啟 8~12 小時以上，極度看重雙迴轉變頻、CSPF 一級超越級省電

🌙 一般家用與睡前定時

下班回家或睡前開啟，追求舒適與價格之間的合理平衡

3. 清潔保養與機體維護習慣？

🧼 懶人科技自體洗淨

希望有「凍結洗淨 3.0」、「UVnano紫外線殺菌」或「離子主動抑菌」功能

🛠️ 手動 Easy Clean 易拆洗派

希望出風口、風道與風輪可以輕鬆手動拆卸，方便定期擦拭清潔

🧹 定期委外專業保養

無特殊自潔需求，習慣定期請專業師傅到府清洗

4. 特殊生活場景需求（可多選）

📱 App 遠端控溫 / 智慧家庭

出門在外預先開冷氣，或透過手機即時監測電力消耗

🤫 極致安靜與氣流不直吹

淺眠怕噪、需要康達氣流或 19dB 極低運轉音

🐾 過敏兒 / 寵物家庭

需要強效空氣淨化離子、除臭與抑菌濾網

🌊 沼氣 / 潮濕高腐蝕環境

靠近夜市、排水溝、溫泉區或潮濕山區，需要強化防沼氣設計

🛋️ 大客廳 / 長型空間

需要強勁噴射氣流與超遠吹風距離快速冷房

5. 冷暖功能類型？

🔥 冷暖變頻 (推薦主流)

冬暖夏涼，冬天當暖氣開比電暖器省電 70% 以上

❄️ 單冷變頻

僅在夏天熱時開啟降溫
